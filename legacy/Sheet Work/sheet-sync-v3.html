Sheet Sync

Update an old Excel sheet from a newer one. You decide what is protected and which changes are applied. Works offline; your files never leave this computer.

Choose your files

Click a box or drop files onto it. Dropping two files anywhere on the page fills Old then New.

Sync every sheet that has the same name in both files
Column mapping (columns whose names differ)

Pair a column in the old file with the column in the new file that holds the same data. Mapped columns are treated as one column everywhere below.

Match rows by

Tick Key on one or more columns in the list further down. Several ticked columns are matched together (for example Name plus Date).

Ignore upper/lower case and extra spaces in keys
Suggest matches for keys that are almost the same (at least 85% similar)Rows that find no exact match are compared with each other. Suggestions are only used after you confirm them in the review step.
What should happen to each column

Update takes the new value. Fill empty only writes only into empty cells. Keep old never overwrites (the new value is still listed so you can override). Merge combines old and new text. Ignore skips the column. Use the more button for type, per-column similarity, "only when higher/lower/later", never-blank and unseen-value checks.

Protect your edits in the old file
Never overwrite cells that are highlighted in the old fileAny background fill colour counts.
If the key cell is highlighted, protect the whole row
Never overwrite cells that contain a formula in the old file
Protect cells I edited since the baselineA cell counts as edited when the old file differs from the baseline in that cell.
Also protect rows that are not in the baseline (added by hand)
Conditional rules

Keep the old value when a condition is true. Example: protect Status when old Status is one of Closed, Done.

Ignore small changes and comparison rules
Treat a change as minor when the new text is at least 90% similar to the oldMinor changes go to their own tab, so nothing is lost silently.
A change that alters digits is never minor"A-10045" to "A-10046" is always reviewed.

Ignore accents
Ignore leading zeros (007 = 7)
Treat N/A, null, none and - as empty
Clean hidden characters before comparing (non-breaking spaces, line breaks, zero-width marks)
