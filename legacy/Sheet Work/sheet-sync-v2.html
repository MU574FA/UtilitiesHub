Sheet Sync

Update an old Excel sheet from a newer one. Matched rows are updated, new rows are added. You decide what is protected and which changes are applied. Works offline; your files never leave this computer.

What should happen to each column

Update takes the new value. Fill empty only only writes into cells that are empty in the old file. Keep old never overwrites (the new value is still listed so you can override it). Ignore skips the column.

Protect your edits in the old file

Never overwrite cells that are highlighted in the old fileAny cell with a background fill colour counts. Colour the cells you edited by hand and they are kept.
If the unique-column cell is highlighted, protect the whole row

Protected changes are not applied by default, but they stay visible in the review step where you can still apply any of them.

Ignore small changes

Treat a change as minor when the new text is at least 90% similar to the oldGood for typo fixes, spacing and punctuation. Minor changes are put in their own tab, so nothing is lost silently.
A change that alters digits is never minorSo "A-10045" to "A-10046" is always reviewed, even though the text is 86% similar.
