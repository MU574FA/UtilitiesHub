Excel Merger

Combine an old copy and a new copy of a spreadsheet into one file. Match rows by a key column, decide which version wins for each column, fix single cells by hand, and download the result with the changes highlighted.

1Add both files

Tip: when you pick or drop two files together, the one saved earlier becomes the old copy. Supports .xlsx, .xlsm, .xls, .csv and .tsv. Files stay in your browser and are not uploaded anywhere.

2Choose how to merge

Combine rows by
Columns: choose what to include, the order, and a rule for each column

Set a different rule for a single column, for example add stock counts together while taking prices from the new file. Untick a column to leave it out of the result.

3Review the result
